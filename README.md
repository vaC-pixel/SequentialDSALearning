# Sequential DSA Learning Roadmap 🚀

A structured, step-by-step repository for mastering Data Structures and Algorithms from scratch.

---

## 🗺️ Roadmap Overview

- [ ] **Phase 1: Basic Arrays & Math**  
  *Iteration, element manipulation, basic math/digit logic.*
- [ ] **Phase 2: Two-Pointer & Sliding Window**  
  *Optimizing linear scans, sub-ranges, partitioning (e.g., Move Zeros problem).*
- [ ] **Phase 3: Prefix Sum & Kadane's Algorithm**  
  *Running calculations, subarray patterns.*
- [ ] **Phase 4: Sorting & Binary Search**  
  *Finding elements efficiently in sorted data.*
- [ ] **Phase 5: Strings & Basic Hashing**  
  *Frequency maps, character manipulation.*
- [ ] **Phase 6: Recursion & Backtracking**  
  *The foundation for advanced problem-solving.*
- [ ] **Phase 7: Linear Data Structures**  
  *Linked Lists, Stacks, Queues.*
- [ ] **Phase 8: Non-Linear Data Structures**  
  *Trees, Graphs.*

---
